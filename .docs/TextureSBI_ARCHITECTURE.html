Paper-ready architecture reference

TextureSBI-B0

Lightweight texture-only RGB video classifier with clip-coherent Self-Blended Images (SBI) training.

Model family TextureSBI EfficientNet-B0 + mean temporal pooling
!
Drawing rule for the paper

The deployed model has one learned RGB branch. Landmarks are used only for preprocessing and the SBI generator is training-only; neither is an inference-time feature branch.

What is temporal in this model? Only the uniform selection of texture frames and the arithmetic mean over their embeddings. The temporal operator has no learnable parameters and adds negligible computation or memory.

Do not draw these as model branches

Important exclusions

  • Landmark coordinates are not passed to the classifier.
  • SBI is not used during validation or test inference.
  • There is no TCN, attention, residual temporal block or RNN.
  • Mean pooling is fixed arithmetic averaging, not a learnable layer.
